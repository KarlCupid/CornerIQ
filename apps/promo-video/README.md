# CornerIQ Promo Video

Vertical Remotion promo for CornerIQ.

## Commands

```bash
npm run preview
npm run render
```

The rendered MP4 exports to:

```text
apps/promo-video/out/corneriq-promo.mp4
```

## Assets

The video uses real mobile screenshots in `public/screenshots/`.
No fake app screens are generated.
